# Yesha WEB Activities

This package keeps the homepage design and its CSS/JavaScript from the first Yesha WEB Activities ZIP. The activity cards point to the uploaded original activity files stored in `public/original-activities/`; those original HTML/CSS/JS/image files were extracted without editing their contents.

## Deploy on Vercel
1. Extract this ZIP.
2. Upload the contents to a GitHub repository (including the `public` folder and `vercel.json`).
3. Import the repository in Vercel.
4. Set Framework Preset to Other, Root Directory to `./`, Output Directory to `public`, and leave build/install commands blank.
5. Deploy.

Note: The homepage image assets are whatever was present in the original homepage ZIP. Replace/add your own `public/yesha.png` and `public/pink.jpg` only if you want those specific homepage images; the activity source files are kept separate and unchanged.
